# 原创自主导演规程 · v0.23

Codex 对内容表达和制作步骤有自主权：理解全文，决定分镜和节奏，观察/选择素材，按需要调用图片、视频、TTS 与动画工具，并检查真实结果。Video App 不再围绕 video-use 的已有视频剪切组织主流程，也不把一段正文强制投影成一个镜头。

| 组件 | 职责 |
| --- | --- |
| Codex | 内容理解、导演决策、分镜选材、生成提示、动画实现、修改与检查 |
| RunDesk | 运行环境、Skills/MCP 配置、会话、任务生命周期、轨迹与通用诊断 |
| Video App | 可组合制作工具、素材来源、工程与修订、异步任务、产物归档和专业审阅 |
| HyperFrames | 执行原创 HTML/CSS/JavaScript/GSAP 动画并渲染画面；音频按工程合成 |

## 自由创作与可靠执行

原稿的事实、限定语和归属是内容边界。素材必须服务文字；生成示意不冒充新闻现场或事实证据。内容规划使用自由文档，精确引用只用于指认原文和保存选择理由，不要求全文先切成固定 scene，也不要求一句一图。

剪辑记录约束时间、素材、字幕和声音安排；HTML/CSS/JavaScript 负责自由动画表达。工程声明、实际 DOM 与渲染必须一致；审阅轨道是工程的展示，不是另一份独立剪辑状态。每种后端只保留一份实际渲染依据，禁止同时修改 native DSL 和 HyperFrames 却让用户猜哪份生效。

用户一键制作授权在既有输入、配置服务和费用范围内完成普通初稿；阶段记录不是审批。工具负责严格参数、来源、时序、幂等与修订检查，Skill 不增加逐镜头确认。真实阻塞、事实改写或超出已有授权的资源才需要人的决策。最终人审针对具体完整输出，Agent 不自动发布或宣称终稿。

## 阶段是可检查产物

- **素材准备和对齐**：自由导演简报、实测配音、真实素材观察、精确文字与素材关系、缺口与回退。
- **剪辑**：原创 HyperFrames 工程、声明的多轨时间线、校验与完整初稿。
- **精修**：实际输出检查、按文字或片段的局部修改、新输出及未验证事项。

阶段可以交错与返回，TTS、找素材、画动画的顺序由实际任务决定；图像/视频生成成功只是素材，不表示剪辑或成片完成。局部修改保留无关素材、稳定对象 ID 与满意的编辑，不全量重做来掩盖缺少定位。

## 兼容性与能力诚实

新项目采用 HyperFrames，旧项目保留原有后端。native DSL、video_use EDL 和旧镜头只按实际已实现能力使用；不声称彼此同等支持动画、音乐或多轨。旧 video_use 生产快照与共享目录流程不属于 HyperFrames 必需路径。

合成块时序不是逐字对齐；文字关联不是事实或语义正确性证明；元数据、样本帧与可见 DOM 校验均不能证明听审或全片质量。报告应列明确实检查的输出、时间点和未执行的检查。运行诊断不会通过调用模型或远端生成来假装完成验收。

## 原创与持久化

这里只参考 OpenMontage 的阶段产物和成片检查方法，没有复制其代码、Schema 或 Skill。HyperFrames 与 GSAP 是单独的渲染依赖，按其自身协议安装和使用。

Skill 在 App 仓库维护，并同步到 RunDesk video-build 的完整 Skill 目录；该镜像保留 build-video-artifacts 名称，App 保留 video-project 名称。App 的版本化基础 Skill 与分阶段提示需使用相同的职责、工具和能力边界，不保留“默认 video-use”或固定镜头模板的旧指令。
