验证日期：2026-09-29。Linux amd64、Go 1.27.1、FFmpeg/FFprobe、HyperFrames 0.8.87、GSAP 3.15.0、Chrome for Testing 154.0.8037.57。

## 已通过

- `go test -race ./...`：23 个顶层测试及 1 个示例通过，含各测试中的子场景。新增覆盖字幕采用、正文/起点失效、显式核对、字幕草稿、版本冲突、重启恢复、并发元数据保留、SRT 边界、HTML 转义和渲染副本音频篡改。
- `go vet ./...`、前端与验收脚本 JavaScript 语法检查通过。
- `scripts/smoke-news.py` 13 项检查通过：沿用真实 Python 稿件/成片包和 RunDesk v0.5.4 演示实例，真实 stdio MCP 调用原片音轨采用与字幕修改；确认七个工具、版本更新、来源保留和改稿后字幕失效。
- `scripts/smoke-subtitles.cjs` 9 项浏览器/媒体检查通过：从页面导入新闻包、接收原片、采用音轨和字幕、定位字幕试听、实际生成 MP4、保存 SRT 快照、正文变更阻止渲染、字幕编辑需人工核对、并发编辑保留本地 SRT 草稿、原片不变及无页面 JavaScript 异常。
- 实际重新渲染的 MP4：1080×1920、H.264、30 fps、约 7.833 秒，含 48 kHz 双声道 AAC。分别检查音视频流时长，偏差小于 40 ms；不是仅检查容器时长。
- 抽取 1 秒和 4 秒画面，分别可见第一段与第二段中文字幕，版面无重叠、乱码。字幕源时间为 0–3.215 秒及 3.215–7.821 秒；快照 SRT 与采用内容相同。
- Linux amd64 二进制在验收中实际运行；Windows amd64 交叉编译通过。

示例见 examples/subtitled-app.mp4；新增界面截图见 docs/subtitle-preview.png。配套报告摘要位于 docs/validation-0.4-results.json。

## 仍未验证或未实现

- RunDesk 的模型侧使用 demo；没有在用户登录的 Codex 实例执行真实模型推理及模型自主 MCP 调用。独立 stdio MCP 调用已真实执行。
- 浏览器测试会自动点击人工核对确认，只验证状态与接口，不代表人声转写准确率或新闻事实审核。示例声音是离线 eSpeak NG 机械音。
- 尚未在 Go APP 中接入自动 TTS、ASR/强制对齐；用户改稿可能需要自行生成并上传新配音。
- 未做 Windows 真机运行、长视频压力和断电测试。普通重启恢复已覆盖；异常终止可能留下未引用的音频副本或临时核对目录。
- 字幕与镜头均为受限的结构化轨道，尚非自由多轨剪辑器。镜头按总长缩放不等于逐镜头语音对齐。
