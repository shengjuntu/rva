# 配音与背景音乐

v0.2.0 在固定竖版模板上增加两条音轨：一条配音、一条背景音乐。先准备音频文件，支持 WAV、MP3、M4A、FLAC、OGG。这一版没有接入 TTS，不会把文字自动合成为语音。

## 操作

1. 创建分镜，确定视频总时长。
2. 上传录制好的配音与音乐，在“声音”区域分别选择素材。
3. 设置起点和音量，保存项目。
4. 点击生成视频，完成后播放成片检查混音。上方素材播放器用于单个原文件试听，不是同步混音预览。

| 参数 | 含义 |
| --- | --- |
| 视频起点 | 音频从成片第几秒开始，例如 2 表示前两秒不播放此轨 |
| 截取起点 | 跳过源文件开头多少秒，例如 0.5 跳过半秒 |
| 音量 | 0–200%；100% 为原始增益，0% 为静音 |
| 循环截取后的音乐 | 音乐不足时重复截取后的片段，直到视频结束；配音不循环 |

例：配音设置视频起点 1 秒、截取起点 0.3 秒、音量 100%。成片前 1 秒没有配音，之后从原配音文件第 0.3 秒开始播放。背景音乐可先使用 15–25% 音量，再根据实际素材听感调整；这不是响度自动匹配。

分镜决定成片长度。配音结束后补静音，超出视频的部分截断。音乐不循环时也遵循同样规则。混音使用峰值限制器减少数字削波，但没有自动压低背景音乐（ducking）、响度标准化或淡入淡出。视频背景原有声音保持静音。

每次生成都会复制所选音频到版本目录，保留分镜、音轨和素材快照。修改当前音轨不会改变已经生成的成片。文件内没有有效音轨、截取起点超过素材时长等情况会显示为失败并记录日志，不会无声忽略。

## Agent / MCP 编辑

项目的 audio 对象形如：

```json
{
  "narration": {"assetId":"已上传音频的ID","volume":1,"start":1,"sourceStart":0.3,"loop":false},
  "music": {"assetId":"已上传音乐的ID","volume":0.2,"start":0,"sourceStart":0,"loop":true}
}
```

MCP 中 volume 使用 **0–2 的线性增益**，不是百分数。更新前读取项目，并使用当前 revision。将某轨 assetId 设为空字符串可停用；发送 audio:{} 清空两轨。省略 audio（或发送 null）保留原音轨，兼容旧客户端。

可以对 Agent 说：“把已上传的旁白放到配音轨，从视频第 1 秒开始；背景音乐音量设成 20%，循环播放。先保存，等我确认再渲染。”

示例 `sample.mp4` 使用合成测试音验证两轨，不是真人配音或成品音乐。
