# 制作系统分阶段计划

核心：内容自由，DSL负责剪辑。正文、图像、视频、图表、动画作为内容产物；轨道、片段、裁剪、字幕、布局、音频与时间锚点进入剪辑DSL。RunDesk/Codex编排，video-app执行。

| 阶段 | 目标 | 状态 / 验收 |
|---|---|---|
| 1 制作服务基础 | 能力注册、素材服务、统一异步任务、MCP | v0.10.0完成服务实现与自动验证；真实部署仍需验收 |
| 2 剪辑DSL | 稳定对象ID、多轨、片段、时间关系、校验、编译和预览 | v0.11.0实现DSL v1及真实FFmpeg验证；高级组件/关键帧仍待扩展 |
| 3 RunDesk制作闭环 | 制作/素材/DSL/检查Skills，已有材料与IndexTTS出片 | 下一阶段：正文+目录通过对话完成可播放初稿并修改 |
| 4 内容生成与对齐 | Image-gen、Video-gen、视频片段检索及语义对齐 | 混合已有/生成内容，一段多画面，后端按实际配置启用 |
| 5 对话精确编辑 | 对象选择、语义操作、差异、撤销与影响分析 | 局部修改准确，正文/配音不被意外改写 |
| 6 效率与质量 | 依赖复用、局部预览、缓存、质量检查、终稿与部署 | 可恢复任务，局部修改复用无关产物 |

外部交付状态为初稿/调整/终稿；内部步骤按制作任务展开。v0.9正文投影仅兼容保留，不作为新系统强制模板。

第三阶段 v0.13：项目级内置 Skill 选择和补充要求、初稿指令生成、一键通过既有 RunDesk 会话派发、实际 Skill 路径核对、原请求恢复已实现。真实 Codex + IndexTTS 全流程验收仍待部署环境验证；任意用户 Skill 导入暂未实现。
