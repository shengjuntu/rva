## 范围与未完成项

- eSpeak NG 是机械预览音，尚未评价生产配音自然度，也未接入神经网络 TTS。
- 字幕时间是独立合成分句的实际音频长度，未进行 ASR 或逐字强制对齐；不保证读音、数字或专有名词正确。
- 浏览器会自动确认“采用/人工核对”以验证交互，不能据此声称通过人工听审或新闻事实审核。
- RunDesk 使用 demo；stdio MCP 已真实执行，但没有在用户已登录的 Codex 实例中完成真实模型推理与自主工具调用。
- Windows 为交叉编译，未实机运行；尤其未验证其进程树取消。未做 10 分钟压力、断电、磁盘满和跨文件系统故障注入测试。
- 任务取消/失败/重启后需新建任务，无自动续跑或垃圾回收。100 个任务上限和有限分镜/字幕轨道仍适用于本版。
