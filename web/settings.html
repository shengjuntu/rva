填写语音 API 地址，不能填写 Gradio 网页地址。连接检查不会生成配音；实际音色和音质需要在制作结果中核对。

图像与视频生成服务

生成服务由管理员在启动配置中连接 HTTP 二进制适配器，本页只展示配置状态；不支持直接填写厂商 API。未配置时可使用已有素材制作。

管理员部署说明

图像适配器使用 VIDEO_IMAGE_GEN_URL、VIDEO_IMAGE_GEN_MODEL、VIDEO_IMAGE_GEN_KEY；视频适配器使用 VIDEO_VIDEO_GEN_URL、VIDEO_VIDEO_GEN_MODEL、VIDEO_VIDEO_GEN_KEY。修改启动配置并重启后刷新状态。配置存在不代表已完成真实生成验收。
